## 安装

- **DSH Desktop**：插件 → 添加插件，填写下载后的 `.tgz` 完整本地路径。
- **DSH Web**：在对应 profile 安装：

```bash
dsh plugin --profile web add '/完整路径/dsh-video-vision-0.9.3-audit.6-copyclarity.tgz'
```

正常重新加载插件。使用 Node.js 22+，FFmpeg/ffprobe 可通过 PATH 或插件设置指定。语音识别复用 DSH 官方已就绪的语音服务；本插件包不附带模型，也不自动下载模型。

## 已完成的云端验收

- 新环境初态、中文/英文、预算输入与重启持久、音频摘要及宿主默认裁剪。
- 16组媒体：本地音视频、高帧率、偏移/VFR、极短与一小时素材、静音、范围与尾帧、错误恢复、分离音轨与字幕。
- 三类预算失败与恢复、停止与后续恢复；原生文件导出、覆盖、无损合并；缓存迁移、忙时保护、四类损坏恢复。
- 新建合成 A/B 浏览器的导入、切换、更新、空快照持久、离线来源显示；双会话请求中途撤权与恢复，最终授权/内置同步关闭。
- 单帧、整项、全部缓存的取消/确认删除；无关文件、原视频、方法和导出保留；跨工作区重建与共享。
- 实际明暗主题、904px窄窗、键盘焦点与禁用状态可读。离线已选来源和主题颜色修复已验证，无新增产品缺陷。
- 用户公开视频通过同一冻结插件工具真实解析、下载并返回六帧；进一步由插件取得独立音轨，使用官方 SenseVoice INT8 对0–15秒英文演唱片段完成非缓存转写。识别链路正常；歌词有漏词、错词，作为识别器质量记录，不认定为插件故障。

上述结果可直接采用，**不要求换到本机再重跑整套**。独立 Electron 组件结果与实际 DSH Desktop 挂接分开记录。

# Video Vision 0.10.0-candidate.4

测试分支候选，非市场发布。

## 本次调整
- 来源名称在中英文切换、已保存及离线状态中一致显示；不要求清理或重新导入。
- 用户可见品牌使用 Video Vision 全称，官方扩展连接名称为 Video Vision browser session import。
- 新配置源视频高度默认 0（不限制）；已有正值保留，设置中可明确改为 0。下载大小预算、分析画面缩放、既有缓存不随之改变。
- 重开设置恢复后端导入中状态并禁重复发起。恢复页取消只针对显示的那次导入；原本同页早取消行为保留。不会自动关闭浏览器、取消离开页面的操作或增加超时与后台轮询。

## 验证边界
源码与实际解包的定向测试记录见本候选 test-artifacts 目录。覆盖语言切换、旧标签、清晰度参数与保存重读、定向取消及快照事务；合成测试不代替实机。

此前 candidate.3 的用户报告支持 Git 安装、官方扩展导入、B站认证及 Windows keyring/DSH 重启读取；不重复其全套验收，不将独立 HTTP 请求称作媒体全链。

正常观看时弹出授权页的原因仍未确定，留待后续复测；本版本不宣称修复该现象。Chrome 全进程退出、多来源、明确采集中取消及实际清理撤销仍按未测记录，不要求本轮追加全量测试。

# 改动与依据

| 原问题 | 依据 | 本候选修正 |
|---|---|---|
| 已选A离线、B仍在线时，原生下拉可能显示B，但后端仍为A | 早前候选实际GUI截图与选源状态不一致 | 保留已选离线A的禁用选项与本地化提示，不自动改变授权来源 |
| primary/error等固定颜色缺少皮肤覆盖入口 | CSS逐项审查与皮肤覆盖需求 | 使用Host主题变量与可选`--vv-*`覆盖，保留原色fallback；补原生select/focus及primary hover |
| 简介开头容易让人理解成只支持列出的两个站点 | 内置解析、保存方法、显式yt-dlp及缓存/导出实现 | 正向说明网络/本地来源、可积累方法、帧/音频/字幕和提取保存；依赖对应实际代码 |

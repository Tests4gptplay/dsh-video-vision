# 改动与依据

平台记录：Linux官方DSH Web已完成本轮基本矩阵，另实际CLI完成公网音视频与官方ASR。Windows/macOS原生窗口、密钥存储与Desktop挂接列为实机验证要求。

## 相对当前正式版的功能变化

- 增加可选下载大小、下载总时限和单项处理时限设置；0保持不限制，任务仍可主动停止。[实现](../../lib/budgets.js)
- 改进长视频、不同帧率/起点及极短音频的时间窗、尾帧和观看进度处理；缓存损坏后重新读取与恢复。[实现](../../lib/engine.js)
- 加强浏览器来源选择、登录态刷新与正在下载时的撤权处理；离线来源明确保留，不把其他来源误显示为当前来源。[实现](../../lib/browser-session.js)
- 设置界面接入Host主题与皮肤覆盖变量，改善明暗主题、原生选择列表和焦点/禁用态。[实现](../../client.js)
- 修复多处程序错误，改善运行稳定性。具体回归方法和实际结果见[用例与公开证据](CASEBOOK.md)。

缓存、提取保存、已有语音接口不是此次才新增；真实公开视频及SenseVoice转写是补充验收，不宣传为新增识别模型或新增模型下载要求。


| 原问题 | 依据 | 本候选修正 |
|---|---|---|
| 已选A离线、B仍在线时，原生下拉可能显示B，但后端仍为A | 早前候选实际GUI截图与选源状态不一致 | 保留已选离线A的禁用选项与本地化提示，不自动改变授权来源 |
| primary/error等固定颜色缺少皮肤覆盖入口 | CSS逐项审查与皮肤覆盖需求 | 使用Host主题变量与可选`--vv-*`覆盖，保留原色fallback；补原生select/focus及primary hover |
| 简介开头容易让人理解成只支持列出的两个站点 | 内置解析、保存方法、显式yt-dlp及缓存/导出实现 | 正向说明网络/本地来源、可积累方法、帧/音频/字幕和提取保存；依赖对应实际代码 |

功能修复与介绍文案分开：冻结6的后端除版本标识外未变；本轮内置明暗主题与窄窗视觉组已完成。文案覆盖层不热改正在测试的包。没有新增网络策略、默认预算、授权限制或轮询重试。

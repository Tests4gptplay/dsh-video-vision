## 本次取舍

不是整体合入旧 review.5，也没有把举例中的 8K 或某一帧率设为产品目标或新上限。

1. **源素材与交付图片分开。** 不再用默认 12 帧、60 秒音频等值拒绝明确的正常请求；默认六帧和 30 秒概览仍保留。用户明确设置的预算、真实源文件范围和解码能力继续生效。原始缓存素材保留。
2. **按运行中的 DSH 规格交付。** 从附件服务读取当前图片字节、像素、单边及格式要求，只在必要时生成接入副本。真正保存附件并读回；存储失败或取消不推进观看进度。上传批次限制不冒充工具总取帧上限；整个模型请求的路由预算仍由 DSH 管理。
3. **音频完整覆盖所请求区间。** 保持 DSH 接受的单声道 PCM16 WAV 和现有识别分段。只有已核对的两类容量错误才拆分被拒绝的窗口；其他错误不盲目重试。低音量指标不再取消明确的转写请求，旧准备状态快照不提前拒绝实际服务调用。
4. **修正确定的误拦截。** 精确时间点优先、去重后核算用户预算；单帧与零帧请求；精确时间点缓存身份；显式备用解析器入口；按源提供的帧率/码率选择；完整音频事件及可选明细预算；结束位置不重复播放末帧。
5. **保留有依据的机制。** 用户取消、输入合法性、用户预算、源站授权、凭据按站点使用、缓存归属与共享状态互斥均保留。原生授权媒体请求与匿名第三方解析器的既定边界不变。没有增加握手、心跳或 watchdog。移除了媒体路径中的插件固定截止时间；浏览器发现和显式登录态导入的既有连接处理不改成视频任务限制。
6. **修正运行时指导传播。** 代码、工具说明、内置指导一起更新；仅迁移已识别的旧自动生成指导前缀，保留追加的用户文字和自定义内容。

## 两条 Android Issue

- **#2：附件保存失败。** DSH 附件组件包含原有源码修复：允许穿越但不可读取的系统祖先目录；硬链接不可用时，以已写完、同步并关闭的临时文件在同一文件系统内重命名发布。完整性、去重、别名和临时文件清理保留。
- **#3：sharp 后端缺失。** 附件候选包直接声明与 `sharp@0.35.5` 匹配的 `@img/sharp-wasm32@0.35.5`。依赖放在真正调用 sharp 的 DSH 附件组件中，而不是作为 VV 无关依赖。

附件 TGZ 是 DSH `0.2.2-rc.1` 对应模块的候选替换包，不是 VV bundle。它保留组件安装身份，使用独立候选版本，不覆盖官方版本。源启动用户也可使用附带的 `dsh-android-attachment-source.patch`。当前两条 Issue 保持开放，没有宣称报告者手机已完成完整链路复测。

## 在新的 Linux 测试目录复跑

需要 Git、Node 26、pnpm 11.28.5、FFmpeg/ffprobe。以下操作只针对新测试目录，不修改既有 DSH 安装。

```sh
mkdir vv-host-replay && cd vv-host-replay
export GITHUB_WORKSPACE="$PWD"
git clone --branch prepare/v0.10.2-review.6 https://github.com/Tests4gptplay/dsh-video-vision.git candidate
git -C candidate checkout 3691509975af146892b53be6dec0640a4bf83a7a
git -C candidate fetch --no-tags origin cde7de6d8a83695291b7c6492805fe04d442f5c0
git clone https://github.com/Tests4gptplay/deepseek-harness.git dsh
git -C dsh checkout 562d10a963a41f31a7793441ab0f20ef521dcc24
mkdir -p out/vv-unpacked controller/.github/vv-host-acceptance
(cd candidate && npm ci --ignore-scripts && npm test && npm pack --ignore-scripts --pack-destination ../out)
tar xzf out/tests4gptplay-dsh-video-vision-0.10.2-review.6.tgz -C out/vv-unpacked
ln -s "$PWD/candidate/node_modules" out/vv-unpacked/package/node_modules
export VV_TARGET_ROOT="$PWD/out/vv-unpacked/package"
cp candidate/test/integration/dsh-host.spec.ts dsh/packages/attachment/attachment-local/tests/vv-package-host.spec.ts
(cd dsh && pnpm install --frozen-lockfile --ignore-scripts && pnpm exec vitest run packages/attachment/attachment-local/tests --reporter=verbose && pnpm exec tsc -b packages/attachment/attachment-local/tsconfig.json)
cp candidate/test/integration/companion-smoke.mjs controller/.github/vv-host-acceptance/
python3 candidate/test/integration/build-companion.py
```

完整逐文件清单见同目录 JSON。原始日志、打包结果和源码压缩包在验收 artifact 中；重跑打包时间可能影响 TGZ 外层哈希，内容核对以逐文件清单和固定源码为准。
